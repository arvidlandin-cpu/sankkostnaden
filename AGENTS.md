## Engineering and release quality

- Use ?qa=1 for browser QA to exclude synthetic analytics; do not click genuine outgoing sponsored links in tests.
- Pass/fail no-overflow and successful CI are NOT evidence of visually acceptable design. Inspect actual assets, crop, typography, text, page transitions, working actions and results. The owner's live visual feedback outranks test-only claims.
- A GitHub merge, successful Cloudflare Pages deployment, correct code on the custom domain, physical iPhone verification, owner design signoff and real approved affiliate income are DISTINCT states. Cloudflare Workers Builds failure can be unrelated to successful Pages.
- Separate real organic sessions, tagged paid/sponsor OUTGOING clicks, and network-authoritative APPROVED commissions; total remains UNKNOWN if any active network lacks verified reports.
